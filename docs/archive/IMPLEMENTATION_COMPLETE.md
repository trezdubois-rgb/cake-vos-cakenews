## 🚀 Quick Start

### 1. Start Development Server
```bash
npm run dev
```

### 2. Visit the Demo
```
http://localhost:5173/gutenberg-demo
```

### 3. Create Your First Article
- Fill in metadata
- Use Gutenberg to create content
- Click "Save Article"
- View in feed at `/mon-flux`
